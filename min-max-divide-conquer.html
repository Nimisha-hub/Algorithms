⛰️ Find Min & Max

Divide and Conquer · split the hills, find the peak and the valley in each part, then combine

Comparisons0
Function calls0
Stack depth0
Naive scan would use0

The array · hills of different heights

Recursion tree · each box is one call

Algorithm

Call stack

RECURRENCE

T(n) = 2T(n/2) + 2

2 sub-problems of size n/2, and 2 comparisons to combine (one for max, one for min).

TIME

O(n)

Every element is processed once, so time grows in a straight line with n.

SPACE

O(1) extra data

No extra array is created. The recursion only keeps about log₂ n calls on the stack.
