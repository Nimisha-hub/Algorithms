# Algo Playground

Interactive algorithm simulators for learning: Stack vs Queue, Binary Search, Merge Sort, Quick Sort, and Min & Max (Divide and Conquer).

## Put it online with GitHub Pages
1. Create a new public repository on GitHub, for example `algo-playground`.
2. Upload everything in this folder, keeping the structure: `index.html`, `.nojekyll`, `README.md` and the `simulators/` folder.
3. Open **Settings > Pages**. Under **Build and deployment**, choose **Deploy from a branch**, pick the `main` branch and the `/ (root)` folder, then save.
4. After about a minute your site is live at `https://YOUR-USERNAME.github.io/algo-playground/`.

## Add another simulator later
1. Put the new `.html` file inside `simulators/`.
2. Open `index.html` and add one more entry to the `SIMS` list near the top of the script (copy an existing entry and change the text and file name).
